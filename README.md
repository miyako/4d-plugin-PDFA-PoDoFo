# 4D Plugin: PDF to PDF/A-3 (PoDoFo)

Converts PDF documents to PDF/A-3 format for Factur-X / ZUGFeRD compliance.

## What is Factur-X?

Factur-X is a Franco-German hybrid e-invoice standard (identical to ZUGFeRD 2.x). It combines a human-readable PDF with a machine-readable XML file embedded within a single PDF/A-3 document.

This plugin handles the first step: converting a standard PDF (e.g., from 4D's `SET CURRENT PRINTER` → Quartz/Print-to-PDF) into a PDF/A-3 compliant document.

## Syntax

```4d
$result:=PDF TO PDFA($inputPath; $outputPath)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `$inputPath` | Text | POSIX path to input PDF |
| `$outputPath` | Text | POSIX path for output PDF/A-3 |
| `$result` | Object | Status object |

### Return Object

```json
{
  "success": true,
  "code": 0,
  "message": "PDF/A-3 conversion successful"
}
```

## How It Works

Uses the [PoDoFo](https://github.com/podofo/podofo) library (LGPL-2.0+) to:

1. Load the input PDF
2. Add XMP metadata declaring PDF/A-3B conformance
3. Embed an sRGB ICC color profile as OutputIntent
4. Save the modified document

This approach works well when the input PDF is already "clean" (embedded fonts, RGB color space) — which is typically the case for PDFs generated by 4D's printing system via Quartz (macOS) or Microsoft Print to PDF (Windows).

## Building from Source

### Prerequisites

- CMake 3.15+
- C++17 compiler
- 4D Plugin SDK (included as submodule)
- PoDoFo library:
  - macOS: `brew install podofo`
  - Windows: `vcpkg install podofo:x64-windows-static-release --overlay-triplets=vcpkg-triplets` (static libraries + static CRT, so the `.4DX` needs no extra DLLs)

### Clone

```bash
git clone --recursive https://github.com/miyako/4d-plugin-PDFA-PoDoFo.git
```

### Build (macOS)

```bash
cd PDFA
mkdir cmake-build && cd cmake-build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build .
```

### Build (Windows)

```bash
cd PDFA
mkdir cmake-build && cd cmake-build
cmake .. -A x64 -DCMAKE_TOOLCHAIN_FILE=path/to/vcpkg/scripts/buildsystems/vcpkg.cmake -DVCPKG_TARGET_TRIPLET=x64-windows-static-release -DVCPKG_OVERLAY_TRIPLETS=../../vcpkg-triplets
cmake --build . --config Release
```

## Limitations

- PoDoFo adds PDF/A-3 metadata and ICC OutputIntent but does **not**:
  - Re-encode non-embedded fonts
  - Remove transparency
  - Convert unsupported color spaces
  - Validate the result against PDF/A specification
- For arbitrary input PDFs, consider using Ghostscript-based conversion instead
- Currently builds arm64 only on macOS (Homebrew PoDoFo is arm64); for universal binary, build PoDoFo from source
